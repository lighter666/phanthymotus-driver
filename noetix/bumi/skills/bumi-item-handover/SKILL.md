# Bumi 办公物品借还现场核验

仅在管理员现场参与办公设备及配件的借还交接时使用。使用画布中已有的 `camera`、`face_recognition` 和 `vision_capture` 卡片。人脸识别用于提出借用人候选，不等于身份认证；不把对话摘要当成正式台账，不声称已自动识别二维码、确认设备功能或跨会话查询借还历史。管理员负责确认借用人、核对实物与原图、完成正式登记。

## 借出时识别借用人

1. 先告知现场人员将进行人脸识别，并请借用人单独面向 Bumi 相机；有人不同意时跳过识别，由管理员按原有流程提供姓名。不要为完成借还而自动调用 `register_by_photo`、`register_by_stream` 或修改人脸库。
2. 确认画布绑定的 `camera → face_recognition` 正在提供新画面；调用已有 `face_recognition` 实例的 `recognize_by_stream`，使用画布实际绑定的实例，不猜 `input_topic` 或创建新实例。该动作应返回 `ok=true`、`faces` 列表。
3. 仅当结果恰有一张人脸，且其 `known=true`、`quality="ok"`、`person_id` 和非空 `name` 均存在时，把姓名和 ID 作为候选读给管理员，由管理员确认眼前借用人就是此人后再写入摘要。匹配分数只能作为辅助信息，不能替代现场确认。
4. 结果为零张或多张人脸、未命名/未知人员、低质量、无近期画面或工具错误时，说明具体情况并请人员调整位置后重试一次；仍不明确时请管理员提供姓名并标记“人工提供，未通过人脸识别”。管理员指出识别错人时以管理员核对结果为准，记录“识别结果不符”，不得把错误候选写成已识别借用人。
5. 归还人可能不是原借用人。归还时沿用原借出记录中的借用人，不用当前镜头中的人脸覆盖；若管理员需要记录实际归还人，可另行识别并单独标注。

## 收集交接依据

1. 区分“借出”或“归还”，请管理员提供或读出资产编号、物品名称和配件清单。借出时先按上节识别借用人；识别失败再请管理员提供姓名。只追问影响本次核对的缺失信息，不猜测编号或姓名。管理员姓名未提供时标为“待补”。
2. 借出时请管理员确认物品标签、主设备、各项配件和可见外观，并给出具体归还时间；时间不明确时标为“待补”，不能自行推断。逐项复述后，请管理员指出差异或更正。
3. 归还时请管理员提供原借出摘要或记录及其来源，并以其中的资产编号、配件和外观说明为核对基线。没有基线时仍可拍照记录现场，但不得声称“与借出时相符”。同型号物品也必须核对实际资产编号；错物、缺件或外观差异逐项记录。
4. 拍摄前请操作者把 Bumi 或物品调整到标签、主设备和配件均在画面内的位置，并确认画面范围。不要自行调用移动或姿态工具找物品。拍到可能涉及隐私的人员或信息时，请操作者调整画面后再拍。

## 拍照与确认

1. 画布没有可用的 `vision_capture` 时说明无法拍照留证，不虚构工具或文件。调用 `vision_capture`，`action="start"`；只有返回 `state="ready"` 才调用 `action="capture_photo"`。
2. 只有拍照返回 `ok=true` 且有非空 `file_path` 时，记录返回的 `captured_at`、`file_path` 和 `frame_age_s`，并说“照片已保存到 Bumi 本机”。`start` 就绪、照片路径文本或其他未完成状态都不是照片已保存的证据。失败时报告工具返回的错误，提醒检查相机；仅在管理员明确要求时重拍。
3. 请管理员在 Bumi 主机打开原图，确认标签、主设备和配件清晰、完整。照片无法证明未进入画面的配件状态；模糊或遮挡时标记“画面未核实”，由管理员明确要求后重拍。不得仅凭保存回执推断画面内容。
4. 拍照后单独请管理员确认实物是否已经交付或接收。借出时，只有管理员确认实物已交付，才标记“现场借出交接已确认”；归还时，只有管理员确认已接收且与原记录逐项核对无差异，才标记“现场核对相符”。有错物、缺件、外观差异、无原记录或未确认时，写明“存在差异，待管理员处理”或“无法判断与借出时是否相符”，不能写成正常归还。
5. 用户中止时停止后续步骤。若实物尚未交接，标记“未完成交接”；若已交接但拍照失败或画面未核实，明确写“实物已交接、照片未取得/未核实”，由管理员按现场流程处理，不把该状态升级为完整留证。

## 交接摘要

按以下字段输出供管理员复制到正式台账；未获得的信息写“待补”。照片保存、画面核实、实物交接和配件相符是不同状态，分别陈述。

- 交接类型：借出 / 归还
- 资产编号、物品名称、借用人、借用人来源（人脸识别候选且管理员已确认 / 人工提供）、现场管理员
- 配件逐项核对结果；可见外观与差异
- 借出约定归还时间（含时区）；归还时原借出记录来源及核对基线
- 照片状态：已保存且管理员已核实画面 / 已保存但画面未核实 / 未取得
- 拍摄时间、本机照片路径（无成功回执时均写“未取得”）
- 实物交接状态、最终现场核对结论、待管理员处理事项

摘要只反映本次对话和工具回执。`vision_capture` 保存的原图需管理员在 Bumi 主机核对；输出路径不是下载链接。正式台账登记结果只能由管理员或实际台账回执确认。
